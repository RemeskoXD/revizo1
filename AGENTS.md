# Agent Instructions

## Caflou Integration
* **ZÁKAZ MAZÁNÍ**: Na Caflou je přísně zakázáno mazat přes API cokoliv.
* Můžete pouze odesílat (POST/PUT) nová data.
* Můžete kontrolovat (GET), zda ID objednávky na Caflou existuje (neprosazujte mazání při smazání u nás).

## Design
* Aplikace musí být optimalizována pro iOS telefony a tablety a vzhledově vypadat "jak by si Apple přál" (minimalisticky, čistě, plynulé animace, zaoblené rohy, velká klikatelná tlačítka 44px+ na mobile).
